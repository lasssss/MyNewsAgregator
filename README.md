# DailyNews — новостной агрегатор с погодой (Telegram-бот)

Собирает новости из RSS-лент, показывает погоду по нескольким городам
и присылает обновления в Telegram.

## Возможности

- **Новости** — агрегация из RSS-лент с фильтрацией по словам и регионам
- **Погода** — текущая погода + прогноз на 3 дня (Open-Meteo, бесплатно, без ключа)
- **Несколько городов** — выбор города кнопками в Telegram
- **Авто-рассылка** — новые новости и изменения погоды отправляются в чат
- **Пиннинг лент** — приоритетные источники всегда вверху
- **Inline-кнопки** — удобное меню в Telegram
- **Web UI** — веб-интерфейс для управления настройками
- **RSSHub** — поддержка сайтов без RSS (YouTube, Telegram, Twitter/X и др.)

## Установка

```bash
pip install -r requirements.txt
```

## Настройка

1. Создай бота через [@BotFather](https://t.me/BotFather) и получи токен.
2. Задай переменные окружения (Windows PowerShell):

```powershell
$env:BOT_TOKEN = "твой_токен"
$env:CHAT_ID = "свой_telegram_id"
```

`CHAT_ID` нужен для авто-рассылки. Можно узнать через [@userinfobot](https://t.me/userinfobot).

### Дополнительные переменные

| Переменная | Описание | По умолчанию |
|---|---|---|
| `ADMIN_ID` | Числовой ID админа (без неё настройки доступны всем) | — |
| `WEB_TOKEN` | Пароль веб-интерфейса (без него вход открыт) | — |
| `SETTINGS_FILE` | Путь к файлу настроек | `settings.json` |
| `RSSHUB_BASE` | Адрес инстанса RSSHub | `https://rsshub.app` |
| `WEB_HOST` | Хост веб-интерфейса | `0.0.0.0` |
| `WEB_PORT` | Порт веб-интерфейса | `8090` |
| `WEB_BASE` | Публичный URL веб-интерфейса (для ссылки в боте) | `http://localhost:8090` |

## Запуск через Docker (OpenMediaVault 8)

### Вариант A: Portainer (рекомендуется)

1. Создай репозиторий на GitHub/Gitea/GitLab и залей содержимое проекта.
   `.env` в репозиторий не попадёт (см. `.gitignore`).

2. В Portainer: **Stacks → Add stack → Git repository**. Укажи URL репозитория.

3. В разделе Environment Variables добавь:

```
BOT_TOKEN=твой_токен
CHAT_ID=свой_telegram_id
ADMIN_ID=твой_id
WEB_TOKEN=пароль_веб_интерфейса
```

4. Нажми **Deploy**. Обновления: `git push` → в Portainer открой стек → **Update**.

### Вариант B: без Portainer, через плагин Compose OMV 8

1. Собери и запушь образ:

```bash
docker build -t USERNAME/dailynews:latest .
docker push USERNAME/dailynews:latest
```

2. В `docker-compose.yml` замени `build: .` на `image: USERNAME/dailynews:latest`.

3. На OMV: **Services → Compose → Files → Add**, вставь `docker-compose.yml`,
   добавь переменные окружения.

4. Выдели файл и нажми **up**.

## Команды бота

### Просмотр

| Команда | Описание |
|---|---|
| `/start` | Приветствие и главное меню с кнопками |
| `/news` | Последние новости (по фильтрам) |
| `/news all` | Все новости (без фильтров) |
| `/sources` | Список источников |
| `/weather` | Погода (выбор города кнопками) |
| `/cities` | Список городов для погоды |
| `/settings` | Текущие настройки |
| `/help` | Справка по командам |

### Настройка (только админ)

| Команда | Описание |
|---|---|
| `/addfeed URL [название]` | Добавить RSS-источник |
| `/autofeed адрес [название]` | Автоматически найти RSS-ленту сайта |
| `/removefeed номер` | Удалить источник |
| `/addcity Город` | Добавить город для погоды |
| `/removecity номер` | Удалить город |
| `/keywords слово1, слово2` | Фильтр по ключевым словам (пусто — отключить) |
| `/regions регион1, регион2` | Фильтр по регионам (пусто — отключить) |
| `/priority регион1, регион2` | Приоритетные регионы (всегда вверху) |
| `/pin номер` | Закрепить источник |
| `/unpin номер` | Открепить источник |
| `/pins` | Список закреплённых |
| `/rsshub адрес` | Сменить инстанс RSSHub |
| `/interval минуты` | Интервал проверки (мин. 1) |
| `/broadcast on|off` | Авто-рассылка новостей |
| `/weatherbroadcast on|off` | Авто-рассылка погоды |

## Веб-интерфейс

Открой `http://<IP_NAS>:8090` в браузере.

Управление:
- Источники (добавление, удаление, пиннинг)
- Автопоиск RSS по адресу сайта
- Города для погоды (добавление, удаление)
- Ключевые слова и регионы
- RSSHub, интервал, авто-рассылки

Пароль — через переменную `WEB_TOKEN`.

## Погода

Используется [Open-Meteo](https://open-meteo.com/) — бесплатно, без API-ключа.

- Города задаются через `/addcity` (бот) или Web UI
- Координаты определяются автоматически по названию
- Прогноз: температура, ветер, осадки на 3 дня
- Авто-рассылка: при изменении температуры или условий

## Сайты без RSS (RSSHub)

Если у сайта нет RSS-ленты, автопоиск пробует получить ленту через RSSHub.

В `docker-compose.yml` бот работает с собственным инстансом RSSHub
(сервис `rsshub`, образ `diygod/rsshub`). Внешний порт — `1200`.

Смена адреса: `/rsshub адрес`, поле в Web UI или переменная `RSSHUB_BASE`.

## Настройка источников по умолчанию

Отредактируй список `RSS_FEEDS` в `config.py`. Интервал — `CHECK_INTERVAL_MINUTES`.

```
docker-compose.yml — оркестрация (бот + RSSHub)
```
